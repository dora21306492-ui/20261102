# 認識台灣原生種 — 多媒體測驗系統（p5.js）

PBL 專題「設計我的多媒體測驗系統」期中作業。

## 功能
- 首頁：台灣島與原生種動畫背景、音量按鈕（滑過展開滑桿）、開始／其他
- 角色設計：男／女、長中短髮、髮色、膚色、服裝、眼鏡、鬍子、帽子，之後可從主畫面重新修改
- 主畫面＝探險家工作站：角色可在房間走動（點地板／方向鍵／WASD），走到桌子進入桌面（圖鑑冊、考卷、拼圖盒、配對卡片、相機）；牆上有公告板（每日挑戰）、獎狀櫃（成就）、鏡子（換造型）
- 新手教學（第一次進入自動出現，右上「？」可重看）、固定高度的知識翻頁卡
- 每日挑戰（連續天數）、10 個成就、明信片拍照（可下載圖片；放入真實照片會自動換成主圖）
- 三種遊戲：拖曳配對、點選闖關（含聽聲音題）、答題解鎖拼圖；15 種題庫每次抽 8 種
- 立即回饋、解說卡、✓／✗、最高分（localStorage）、成績高於 60% 才放彩帶
- 電腦（左右分割）與手機（上下堆疊）各自獨立版面

## 檔案
index.html、style.css、config.js（設定區：專案、學習目標、功能開關、風格、素材清單）、sketch.js（主程式／頁面）、room.js（房間、桌面、教學）、extras.js（成就、每日挑戰、明信片）、games.js（遊戲）、avatar.js（角色）、backdrop.js（背景動畫）、scenes.js（物種場景）、species.js（題庫）、audio.js（音效）、libraries/（p5）、media/（選用的聲音檔與 GIF）

## 對照 PBL 文件
- 學習目標與使用對象：config.js 的 PROJECT，也顯示在首頁的「學習目標」
- 成績面板依學習目標統計達成率；可「錯題再練」；有計時與鍵盤作答（1～4、Enter）
- 作答完按 F12 開 Console，可看到每題作答紀錄表（對應 3-5 測試）
- 素材來源與授權：config.js 的 MEDIA_CREDITS ＋ media/出處.txt，顯示在「其他」頁

## 執行
用 VS Code 的 Live Server 開啟 index.html，或部署到 GitHub Pages。
**請先把 sketch.js 最上方的 `DEV_NAME` 改成你的名字。**

## 字型
Google Fonts「Chocolate Classical Sans」（SIL OFL 1.1），需連網；離線時改用系統中文字型。
